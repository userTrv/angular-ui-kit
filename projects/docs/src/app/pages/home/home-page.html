Headless layer first

Keyboard and ARIA behaviour lives in unstyled directives (uiListbox, uiRovingFocusGroup, CDK menu and overlay). Styled components compose them, so custom widgets reuse the same contract.

Tokens, not overrides

One JSON source compiles to CSS custom properties in three tiers. Light, dark and high-contrast themes plus two densities switch at runtime without re-rendering a single component.

Modern Angular only

Standalone, OnPush, zoneless-ready. Signal inputs, model(), output(), inject(), host bindings. Each component ships from its own secondary entry point.

Forms, both kinds

Controls implement the Signal Forms control contract natively; Reactive Forms and ngModel go through one opt-in ControlValueAccessor directive.

Getting started

  1. Install

    The package is not on npm yet. Build it from this repository and install the tarball; @angular/cdk is a peer dependency.

  2. Add the styles

    The kit ships one stylesheet (tokens + a tiny base layer). The CDK overlay CSS is needed for menus, selects, dialogs and tooltips.

  3. Configure the theme (optional)

  4. Import what you use

    Every component is standalone and lives in its own entry point, so unused components never reach your bundle.

Architecture

Styled Components

ui-select, ui-datepicker, uiButton, ui-table… Visual design only, all values from tokens.

Headless Behaviour directives

@usertrv/ui/a11y, @usertrv/ui/listbox, @usertrv/ui/forms: focus management, key managers, ARIA wiring, forms adapters.

Primitives Angular CDK

FocusTrap, FocusMonitor, LiveAnnouncer, ActiveDescendantKeyManager, Overlay, Menu, Accordion, Scrolling.

Tokens tokens.json → CSS custom properties

Primitive → semantic (per theme) → component tiers, generated by a 90-line script.
