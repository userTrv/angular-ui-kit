Theming & design tokens

All visual decisions live in projects/ui/tokens/tokens.json. A small build script compiles it to CSS custom properties in three tiers, so themes and densities are just different values for the same variables. Switching is a single attribute change on <html> — no Angular re-render.

Three tiers

  1. Primitive --ui-color-iris-600raw values
  2. Semantic --ui-color-primaryintent, per theme
  3. Component --ui-button-radiusper component
